HTML Adventure Quest

A game-style coding challenge I created for learners taking their first steps in HTML. Each level sets one clear task, and learners type their answer straight into the editor. Level 1 covers a heading and a paragraph; Level 2 moves on to lists. Try it on the left.

  • One small, achievable task per level
  • Learners write real code, not multiple choice
  • Instant feedback: a success message, or a hint about what to fix
  • Two levels so far, with a progress bar and a Next Level button
  • Built in plain HTML and JavaScript, so it runs in any browser
